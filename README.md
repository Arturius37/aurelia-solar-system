# AURELIA 

> An interactive 3D journey through our Solar System.
AURELIA is a small web experiment built to make exploring space feel a little more immersive.
You can move around the Solar System, focus on planets, watch their orbits, and explore basic information about each world.
Nothing complicated, just **space, movement, and a bit of curiosity.**

## What you can do

* Explore the Sun, 8 planets, and the Moon
* Move around the Solar System in 3D
* Select planets and view their information
* Watch planets move through their orbits
* Adjust the simulation speed
* Switch between different viewing scales
* Explore Earth with day/night and city-light effects
* See details like Saturn's rings, stars, clouds, and more

## Controls

`Drag` — Look around
`Scroll` — Zoom
`Click` — Select a planet
`← / →` — Switch planets
`Space` — Pause / resume
`Esc` — Return to overview

## 🛠 Built with

**Three.js** · **WebGL** · **JavaScript** · **HTML** · **CSS** · **GLSL**

No framework. No complicated setup. Just open it and explore.

## 💻 Run locally

```bash
git clone https://github.com/Arthur37/aurelia-solar-system.git
cd aurelia-solar-system
```

Then open `index.html` in your browser.

Some textures and resources are loaded from external sources, so an internet connection may be needed.
